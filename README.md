# Competing mortality and the early-onset colorectal cancer survival paradox

Analysis code for the manuscript:

> Competing Mortality and the Early-Onset Colorectal Cancer Survival Paradox:
> A Population-Based Cohort Study With Exploratory Molecular Triangulation

## Data sources

- SEER 2000-2022: https://seer.cancer.gov/ (access requires a data use agreement; raw data are not redistributed here)
- TCGA COAD/READ: https://portal.gdc.cancer.gov/
- ICGC-COCA-CN: https://dcc.icgc.org/

## Contents

- `scripts/`: final v2 analysis pipeline (11-38) and figure helpers
- `results/`: aggregate result tables generated by the scripts
- `refs/cited.json`: citation metadata
- `sessionInfo.txt`: R and package versions

## Reproducing the analysis

1. Obtain SEER, TCGA, and ICGC data under their respective access agreements.
2. Place the prepared input files in the paths expected by `scripts/11_cohort_selection_v2.R`.
3. Run scripts in numeric order (11 to 38). Figure scripts require the result tables in `results/`.
4. R version and package versions are listed in `sessionInfo.txt`.
